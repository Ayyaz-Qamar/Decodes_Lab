# 🤖 Rule-Based Chatbot Assistant

## 📌 Project Overview

The **Rule-Based Chatbot Assistant** is a simple Artificial Intelligence project developed during the AI Internship Program at DecodeLabs.

This chatbot uses predefined rules and conditional logic to simulate human conversation and respond to user queries. The project demonstrates the fundamentals of Natural Language Processing (NLP) and chatbot development using Python.

---

# 🚀 Features

- Interactive command-line chatbot
- Predefined conversational responses
- Basic NLP logic implementation
- Handles greetings and common queries
- Simple and beginner-friendly architecture
- Fast and lightweight system

---

# 🛠️ Technologies Used

- Python
- Conditional Logic
- Functions
- Basic NLP Concepts


```bash

```

---

## Step 3: Create Virtual Environment

```bash

```

```bash

```


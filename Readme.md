# AI-Based Student Performance Classification System

## Overview
This project is a supervised machine learning classification system that predicts student performance categories using demographic and educational features.

The project was developed as part of the Artificial Intelligence Industrial Training Program.

---

## Features

- Data preprocessing
- Label encoding
- Logistic Regression model
- Model saving/loading
- Streamlit frontend
- Real-time prediction system

---

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Streamlit
- Pickle

---

## Dataset Features

The dataset contains:

- Gender
- Race/Ethnicity
- Parent Education Level
- Lunch Type
- Test Preparation Course

Target:

- Excellent
- Average
- Poor

---

## Machine Learning Workflow

1. Load Dataset
2. Data Cleaning
3. Feature Encoding
4. Train/Test Split
5. Model Training
6. Model Evaluation
7. Save Model
8. Streamlit Deployment
